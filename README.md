# AEGIS — Autonomous External Graph Intelligence System

Автономная система внешней разведки и непрерывного мониторинга цифрового периметра.
Работает целиком со стороны оператора: у клиента ничего не устанавливается.
Бюджет — $0: только открытые источники и open-source инструменты.
Локальная LLM — обязательная часть (объясняет, суммирует, помогает искать), но никогда не источник истины.

## Пять принципов

1. **Agentless / zero footprint.** Никаких агентов, сенсоров, sidecar'ов и доступов внутрь. Клиент даёт только seed (домен, ASN, CIDR, название). Максимум со стороны клиента — одна TXT-запись для подтверждения владения, которую можно удалить.
2. **Осьминог.** Один «мозг» (монолит: граф, история, решения) и много сменных «щупалец» (коллекторы). Щупальце сломалось, источник закрылся — мозг живёт.
3. **Scope-first.** Пассивно изучаем всё, активно трогаем только то, что подтверждённо принадлежит цели и на что есть разрешение.
4. **Evidence-first.** Каждое утверждение системы ссылается на наблюдение (`Observation`) с сырым доказательством. Нет доказательства — нет finding.
5. **$0 и self-hosted.** Свой хост, Postgres, Ollama, открытые API и open-source тулзы. Данные не уходят наружу.
